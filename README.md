## Descripción

Este repositorio contiene los archivos de Python utilizados en la realización del trabajo del curso *Análisis Geoespacial*. El proyecto se organiza en tres carpetas:

- **Datos:** bases de datos a nivel de barrio sobre hurto a residencias, hurto a personas, incautación de estupefacientes, capturas por tráfico o porte de estupefacientes, número de viviendas y número de personas. Incluye también archivos espaciales con la división político-administrativa en barrios y veredas de Medellín, así como la estratificación por manzana. La subcarpeta **Bases Consolidadas** contiene las versiones procesadas y limpias.
- **Scripts:** scripts de Python para la organización de los datos, el análisis de patrones de puntos (con la base `base_area.xlsx`) y el ajuste de modelos Poisson, GLM y datos en áreas (con la base `barrios_final.gpkg`).
- **Presentaciones:** presentaciones con los avances del proyecto.
